# Changelog

## [0.1.0] - 2026-11-24
### Added
- Реализован событийный мониторинг аудиоустройств и громкости через Windows Core Audio (`IMMNotificationClient`, `IAudioEndpointVolumeCallback`).
- Добавлено переключение устройства вывода звука по умолчанию через `IPolicyConfig` (роли `eConsole`, `eMultimedia`, `eCommunications`).
- Реализована генерация 32-битных ARGB-иконок трея под текущий DPI и тему Windows с силуэтами наушников/динамика, цифрами громкости `0–100` (включая компактное `100`) и индикацией Mute.
- Добавлена логика SoundSwitch-цикла по двойному левому клику, сохранение настроек в `%APPDATA%\VolumeSmartIcon\config.json`, ручное переопределение типа значка и опция автозапуска с Windows.
- Добавлены модульные и дымовые тесты для конфига, классификации устройств и рендеринга иконок.
