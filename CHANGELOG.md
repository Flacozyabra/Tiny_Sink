# Changelog

## [Unreleased]
### Added
- Добавлена автоматическая (при запуске и каждые 24 часа) и ручная проверка обновлений через GitHub Releases API (`src/updater.rs`, нативный WinHTTP с проверкой TLS и системным прокси).
- Добавлен компактный адаптивный диалог обновлений `UpdateDialog` (`src/ui.rs`) с отображением текущей/новой версии, прогресс-баром загрузки (МБ, скорость, %) и отменой.
- Добавлено самообновление без `.bat`-скриптов: проверка контрольной суммы из `SHA256SUMS.txt`, переименование в `Tiny_Sink.exe.old`, запуск новой версии с `--finish-update <pid>` и откат при ошибке.
- В корневое меню ПКМ добавлен единственный пункт `Update` с выпадающим подменю («Проверить сейчас», «Проверять автоматически», «Установить vX.Y.Z...», «Открыть релизы на GitHub...»), а также кликабельное уведомление в трее (`NIF_INFO` / `NIN_BALLOONUSERCLICK`).

### Changed
- Обновлена иконка приложения `assets/Tiny_Sink.ico` (16–256 px): овальная чаша-амбушюра раковины с сифоном, голубым центром слива и стрелками переключения; прежний вариант с динамиком сохранён в репозитории как резервная копия `assets/Tiny_Sink_speaker_backup.ico` и в `.exe` не встраивается.
- Весь пользовательский интерфейс приложения и сообщения апдейтера переведены на английский язык (с сохранением эвристик распознавания русских названий аудиоустройств в Windows).
- Модули `ui`, `tray` и `updater` реструктурированы на компактные подмодули (`src/ui/`, `src/tray/`, `src/updater/`).

## [0.1.0] - 2026-11-24
### Added
- Настроен workflow `.github/workflows/release.yml` для автоматической сборки Windows x64 `.exe`, ZIP-архива и `SHA256SUMS.txt` в GitHub Releases по тегу `v*` и ручному запуску.
- Добавлена лицензия MIT (`LICENSE` и метаданные `Cargo.toml`).
- Добавлена регулировка громкости колёсиком мыши над иконкой в трее (шаг `2%`, автоматическое снятие Mute при увеличении громкости).
- Добавлен всплывающий регулятор громкости по одиночному ЛКМ (с задержкой `350 мс` для разделения с двойным кликом), поддержкой перетаскивания, кнопки Mute на значке и скролла.
- Добавлено не закрывающееся при клике тёмное окно «Устройства...» с чекбоксами и пункт быстрого перехода к настройкам системного значка громкости Windows.
- Добавлена адаптивная тёмная тема контекстного меню Windows (`AllowDark` через `uxtheme.dll`) с обновлением при смене системной темы.
- Обновлена иконка приложения `assets/Tiny_Sink.ico` (16–256 px): динамик и две разнонаправленные стрелочки переключения, встраивается в `Tiny_Sink.exe` через `build.rs` и `rc.exe`.
- Реализован событийный мониторинг аудиоустройств и громкости через Windows Core Audio (`IMMNotificationClient`, `IAudioEndpointVolumeCallback`).
- Добавлено переключение устройства вывода звука по умолчанию через `IPolicyConfig` (роли `eConsole`, `eMultimedia`, `eCommunications`).
- Реализована генерация 32-битных ARGB-иконок трея под текущий DPI и тему Windows с силуэтами наушников/динамика, цифрами громкости `0–100` (включая компактное `100`) и индикацией Mute.
- Добавлена логика SoundSwitch-цикла по двойному левому клику, сохранение настроек в `%APPDATA%\Tiny_Sink\config.json`, ручное переопределение типа значка и опция автозапуска с Windows.
- Добавлены модульные и дымовые тесты для конфига, классификации устройств и рендеринга иконок.

### Changed
- Раздел «Цикл переключения» в меню ПКМ переименован в «Устройства...»; в верхних строках меню теперь выводятся только выбранные устройства, а отдельная строка Mute из меню ПКМ удалена.
- Проект оформлен под именем `Tiny_Sink`: пакет Cargo `tiny_sink`, исполняемый файл `Tiny_Sink.exe`, папка конфига `%APPDATA%\Tiny_Sink\config.json`, ключ автозапуска `Tiny_Sink`, внутренние идентификаторы окна и мьютекса.

### Fixed
- Исправлено ложное открытие регулятора громкости после двойного клика (фильтруется завершающий `WM_LBUTTONUP` отпускания второй кнопки мыши, учитывается `GetDoubleClickTime()`, корректно закрывается открытая полоса громкости повторным кликом по иконке).
- Пункт меню «Системный значок громкости Windows...» переведён на современный URI `ms-settings:taskbar` (вместо старой панели `taskbarcpl.dll`, вызывавшей падение `explorer.exe` при обновлении часов).
- В `WH_MOUSE_LL` проверка `ToolbarWindow32` выполняется локально без аллокаций и до вызова `Shell_NotifyIconGetRect`.
